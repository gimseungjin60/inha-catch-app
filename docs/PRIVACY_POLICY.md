# 개인정보처리방침

**최종 수정일: 2026-04-20**

Inha-Catch(이하 "서비스")는 이용자의 개인정보를 중요하게 여기며, 「개인정보 보호법」 등 관련 법령을 준수합니다.

## 1. 수집하는 개인정보 항목

| 구분 | 항목 | 수집 목적 |
|---|---|---|
| 필수 | 이메일, 비밀번호(해시), 이름 | 회원가입·인증, 서비스 이용 |
| 선택 | 학과, 학년, 관심 키워드 | 맞춤 공고 추천 |
| 자동 수집 | 기기식별자(FCM 토큰), 조회·북마크 이력 | 푸시 알림, 추천 알고리즘 개선 |
| 소셜 로그인 | 카카오 식별자, 이메일, 닉네임 | 간편 로그인 |

## 2. 수집 방법

- 회원가입 시 사용자가 직접 입력
- 카카오 소셜 로그인 시 카카오에서 제공 (이용자 동의 하)
- 서비스 이용 과정에서 자동 생성 (조회 이력 등)

## 3. 보유 및 이용 기간

- **회원 탈퇴 시 즉시 파기** (단, 법령에 따라 보존이 필요한 경우 제외)
- 조회 이력: 최근 1년치만 보관, 이후 자동 삭제
- 비활성 계정(1년 이상 미접속): 별도 분리 보관 후 3년 후 파기

## 4. 제3자 제공

원칙적으로 제3자에게 제공하지 않습니다. 단, 아래의 경우 예외:
- 법령에 의한 요구가 있는 경우
- 이용자가 사전 동의한 경우

## 5. 처리 위탁

| 수탁자 | 위탁 업무 |
|---|---|
| Google LLC (Gemini API) | 공고 본문 AI 요약 생성 (이용자 개인정보 전송되지 않음) |
| Google LLC (Firebase) | 푸시 알림 발송 |
| Kakao Corp. | 카카오 소셜 로그인 |

## 6. 이용자 권리

- 개인정보 열람·수정·삭제·처리정지 요구 권리
- 서비스 내 "내 정보" 메뉴 또는 이메일 문의를 통해 행사 가능

## 7. 안전성 확보 조치

- 비밀번호 단방향 해시 저장 (BCrypt)
- HTTPS 암호화 통신
- 관리자 권한 분리 및 접근 로그 기록

## 8. 개인정보 보호책임자

- 이름: (담당자 이름 기입)
- 이메일: (연락처 이메일 기입)
- 소속: 인하공업전문대학 ○○과 ○○팀

## 9. 방침 변경

본 방침은 법령·서비스 변경에 따라 수정될 수 있으며, 변경 시 앱 내 공지합니다.
